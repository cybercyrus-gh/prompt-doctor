# 前后对照示例

## 示例 1：简单任务（只给变体 A）

**原始**："帮我写个请假条"
**诊断**：缺受众（给谁）、背景（几天/原因）、约束（格式）
**变体 A**："帮我写个请假条。请假对象：[直属主管/老师/其他]。请假时间：[日期或天数]。原因：[具体原因]。语气：[正式简洁/自然礼貌]。长度：[100 字内/其他]。"

## 示例 2：内容创作（加锚点解决"去 AI 痕迹"）

**原始**："帮我写篇环保的文章，去除 AI 痕迹"
**诊断**："去 AI 痕迹"是伪需求，真缺口是受众、示例、语气锚点
**变体 A（引导补缺口）**："帮我写篇环保文章。发布渠道：[公众号/内部刊物/其他]。篇幅：[填写]。读者：[填写]。语气：[像朋友聊天/专业科普/其他]。避免：[不想出现的套话或句式]。参考风格：[贴一段你喜欢的样稿]。"
**变体 B（如无样稿，先要选项再写）**："先别写。给我 3 个不同的切入角度（反常识/个人故事/数据驱动），各一句话，我挑一个你再动笔。"

## 示例 3：预测类（预警 + 换用法）

**原始**："龙高股份下周走势预测"
**诊断**：AI 不能可靠给出短期股价的确定性单点预测。优化 prompt 也无法把不确定性变成保证。
**预警 + 改造**："这个任务不适合要求必涨或必跌。建议换成：信息汇总（主营/财报/公告/行业）→ 多空对称（各 3 条最强逻辑 + 假设 + 证伪信号）→ 交叉反驳 → 找关键假设 → 概率/情景化（乐观/中性/悲观 + 触发信号）。要我用这套流程帮你做吗？"

## 示例 4：隐含多任务（拆成链）

**原始**："帮我搞个数控磨床行业的融资报告"
**诊断**：这是 3 件事（行业研究 + 财务框架 + 报告撰写）伪装成 1 件
**变体 B（拆成链）**：
"分三步：① 行业研究：数控磨床市场规模/竞争格局/趋势，每条标信息时间，不确定写'需核实'；② 财务框架：关键指标 + 估值区间 + 假设；③ 报告：基于①②成文，1500 字，给投资人看。先做①，做完我确认再继续。"

## 示例 5：角色 + 量化（公文类）

**原始**："写个村书记事迹材料"
**诊断**：缺角色视角、背景事迹、验收标准
**变体 A**："以县委组织部评审视角，写一份参选县级优秀党员的事迹材料，对象：[某县某镇某村]党支部书记/村委会主任。背景事迹：[补 3-5 件具体事，含数据]。格式：1500 字，第三人称，分'政治素质/带头创业/服务群众'三块。验收：读完能记住 3 个具体故事。"
