# 前后对照示例

## 示例 1：简单任务（只给变体 A）

**原始**："帮我写个请假条"
**诊断**：缺受众（给谁）、背景（几天/原因）、约束（格式）
**变体 A**："帮我写个请假条。请假人：我，普通员工。请假对象：直属主管。天数：3 天。原因：感冒发烧。语气：正式简洁，100 字内。"

## 示例 2：内容创作（加锚点解决"去 AI 痕迹"）

**原始**："帮我写篇环保的文章，去除 AI 痕迹"
**诊断**："去 AI 痕迹"是伪需求，真缺口是受众、示例、语气锚点
**变体 A（引导补缺口）**："帮我写篇环保文章，1000 字，发公众号。读者：25-35 岁城市白领。语气：像和朋友聊天，不端着。避免：排比开头、'在当今…时代'、'综上所述'。参考风格：[贴一篇你喜欢的公众号文章]"
**变体 B（如无样稿，先要选项再写）**："先别写。给我 3 个不同的切入角度（反常识/个人故事/数据驱动），各一句话，我挑一个你再动笔。"

## 示例 3：预测类（预警 + 换用法）

**原始**："龙高股份下周走势预测"
**诊断**：AI 本质做不了短期股价预测。优化 prompt 也救不了。
**预警 + 改造**："这个任务优化 prompt 也救不了——AI 预测不了短期股价。建议换成：信息汇总（主营/财报/公告/行业）→ 多空对称（各 3 条最强逻辑 + 假设 + 证伪信号）→ 交叉反驳 → 找关键假设 → 情景化（乐观/中性/悲观 + 触发信号）。要我用这套流程帮你做吗？"

## 示例 4：隐含多任务（拆成链）

**原始**："帮我搞个数控磨床行业的融资报告"
**诊断**：这是 3 件事（行业研究 + 财务框架 + 报告撰写）伪装成 1 件
**变体 B（拆成链）**：
"分三步：① 行业研究：数控磨床市场规模/竞争格局/趋势，每条标信息时间，不确定写'需核实'；② 财务框架：关键指标 + 估值区间 + 假设；③ 报告：基于①②成文，1500 字，给投资人看。先做①，做完我确认再继续。"

## 示例 5：角色 + 量化（公文类）

**原始**："写个村书记事迹材料"
**诊断**：缺角色视角、背景事迹、验收标准
**变体 A**："以县委组织部评审视角，写一份参选县级优秀党员的事迹材料，对象：[某县某镇某村]党支部书记/村委会主任。背景事迹：[补 3-5 件具体事，含数据]。格式：1500 字，第三人称，分'政治素质/带头创业/服务群众'三块。验收：读完能记住 3 个具体故事。"
