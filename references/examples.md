# 前后对照示例

这些示例展示模式，不是固定模板。

## 简单成品：最小升级

**原始**

```text
帮我写个请假条。
```

**诊断**：缺少对象、时间、原因和长度；不需要复杂角色设定。

**优化版**

```text
帮我写一则发给直属主管的请假消息。请假时间：[待填写：日期或天数]，原因：[待填写：原因]。语气礼貌、直接，控制在 100 字以内。
```

## 风格不明确：用可观察特征

**原始**

```text
写篇环保文章，去掉 AI 味。
```

**诊断**：“AI 味”无法直接执行，需改成受众、场景和可观察的语言特征。

**优化版**

```text
为面向城市上班族的公众号写一篇环保文章。用一个日常生活场景开头，围绕具体可行的行动展开，并说明现实成本或限制。语气像朋友分享经验：句子简短，多用具体例子，少用抽象口号。避免“在当今时代”“让我们携手”“综上所述”等套话。不要编造数据；需要数据但无法核实时标记“待核实”。篇幅：[待填写；若无偏好，默认约 1000 字]。
```

## 复杂任务：拆阶段并设置停止点

**原始**

```text
帮我做一份工业设备行业融资报告。
```

**诊断**：行业研究、财务分析和成文被混成一个任务，且缺少公司材料与报告受众。

**优化版**

```text
目标：为 [待填写：投资人/银行/内部决策层] 准备一份工业设备公司的融资分析报告。

可用材料：
- 公司与产品：[待填写]
- 财务数据：[待填写]
- 行业资料：[待填写或注明允许检索]

分三步执行：
1. 先列出仍缺少的关键事实，并给出行业、竞争、商业模式、财务和风险五部分的研究提纲。输出后停止，等我确认。
2. 基于确认后的材料完成分析。区分事实、推断和待核实项；关键数字注明来源与日期。
3. 生成报告，并用“论点是否有证据、数字是否可追溯、风险是否具体”三项自检。

不要在材料不足时虚构公司数据或市场规模。
```

## 不可靠预测：改成情景分析

**原始**

```text
预测这只股票下周会涨还是跌。
```

**诊断**：短期方向无法通过提示词可靠预测，应把单点答案改成可核查的情景分析。

**优化版**

```text
不要预测下周必涨或必跌。基于截至 [待填写：日期] 可核实的信息，整理影响该股票短期波动的主要因素。分别给出乐观、中性和悲观三种情景；每种情景列出依据、关键假设、触发信号和会推翻该情景的新证据。区分已知事实与推断，并标记无法核实的信息。最后说明哪些变量最值得持续观察。
```

## 局部编辑：保护未授权范围

**原始**

```text
把第二段写得口语一点。
```

**优化版**

```text
只修改下文第二段，使表达更口语、更自然。保留原有事实、数字和立场，不新增观点；第一段及其余内容一字不动。输出完整文本，并将修改后的第二段加粗。
```
