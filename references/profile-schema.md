# 个人提示词画像格式

本文件定义 `references/profile.local.md` 的创建、更新和使用规则。个人画像只帮助 Prompt Doctor 调整诊断优先级，不代替对当前 prompt 的独立判断。

## 存储与隐私

- 仅在用户明确同意后创建或更新 `references/profile.local.md`。
- 画像只保存在本机；仓库通过 `.gitignore` 排除该文件。
- 不保存原始 prompt、实际输出、姓名、联系方式、财务数据、公司内部信息或其他敏感内容。
- 只写抽象特征：检查表维度、重复模式、证据次数、置信度、最近观察日期、有效改法和稳定偏好。
- 通用案例库与个人画像分别征求授权；对其中一处的同意不适用于另一处。

## 形成门槛

1. 首次出现只在当前会话观察，不询问、不写入。
2. 同一模式在至少两次独立任务中出现，或用户主动说明固定弱项 / 偏好时，可询问是否记录为“待验证”。
3. 同一模式出现至少 3 次，且用户反馈对应改法有效时，可升级为“已验证”。
4. 新证据与旧结论冲突时，降低置信度、改写或删除；不要让画像只增不减。
5. 更新已有模式时合并证据，不重复追加同义条目。

## 文件模板

```markdown
# 个人提示词画像

最后更新：[YYYY-MM-DD]

## 常见弱项

### [检查表维度]

- 状态：待验证 | 已验证
- 证据次数：[整数]
- 置信度：低 | 中 | 高
- 最近观察：[YYYY-MM-DD]
- 抽象模式：[不包含原始 prompt 的一句话概括]
- 有效改法：[经过反馈验证的修正方式；未验证时写“待验证”]

## 使用偏好

### [偏好名称]

- 状态：待验证 | 已验证
- 证据次数：[整数]
- 置信度：低 | 中 | 高
- 最近观察：[YYYY-MM-DD]
- 偏好：[例如“默认只给最小升级版”]
- 适用边界：[何时不应套用]
```

## 使用规则

1. 先独立诊断当前 prompt，再读取画像调整复查顺序。
2. 已验证弱项可以优先检查；待验证条目只作轻量提醒。
3. 画像不能证明当前 prompt 一定有某个缺口，也不能覆盖用户本轮要求。
4. 不必在每次回复中展示画像；只有它实际影响处方时，才用一句话说明。
5. 用户要求查看、修改或清空时直接照办；清空画像不影响通用案例库。
